# Musique — ACE-Step Create (léger)

Override de `MASTER.md` pour l’onglet Musique.

## Flux (inspiré acestep.io/create, sans Cover/Stems)
1. **Presets** mood (chips) + option « partir de la bibliothèque »
2. **Ambiance** — caption ACE-Step
3. **Voix** — Instrumental | Avec paroles (+ lyrics + tags `[Verse]` / `[Chorus]`)
4. **Durée** + options avancées (BPM, tonalité, seed)
5. **Résultat** — carte hero (player, Regénérer, Variante seed)

## Params job
`prompt`, `durationS`, `instrumental`, `lyrics`, `seed?`, `bpm?`, `keyscale?`

## Hors scope
Cover, Extend, Stems, Remove Vocals, forest de samplers.
